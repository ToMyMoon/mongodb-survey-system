# 第二阶段需求与设计确认

本文汇总本轮讨论中用户明确确认的规则，作为第二阶段实现依据。用户随后授权实现，第二阶段已在独立项目目录完成代码扩展、建立新集合并导入旧数据，实施结果以项目中的测试报告为准。第一阶段保持为完成基线。

## 1 模板操作与来源历史

- 模板从用户自己的问卷题目保存，草稿和已发布问卷均可作为来源；发布问卷取对应发布内容。
- 模板仅提供保存、使用、删除，不允许直接修改模板正文。
- 保存时固定题型、题干、选项及顺序、必答设置和校验限制，并记录来源信息；不保存问卷内位置、跳转规则及已有答案。
- 使用时复制为问卷内独立题目。原题、模板及使用后的副本互不回写；修改副本不强制保存新模板。
- 修改副本后可以另存为新模板，并保留直接来源模板关系。每条保存记录有独立 ID 和完整内容，允许形成分支，不设置独立的正式题目版本发布流程。
- 加入模板时该题必须完整合法，但不要求整份来源问卷已完成或发布，也不检查模板不携带的跳转。
- 删除仅从可用模板列表移除，保留历史正文及来源关系，不破坏已有问卷和答卷。
- 历史模板可恢复到可用列表，保留原 ID、正文及来源，不覆盖其他模板或问卷；恢复只改变当前用户自己的收录状态，不新增或撤销共享授权。

## 2 使用与问卷编辑

- 问卷草稿中的模板副本可修改题型、题干、选项、必答、校验、顺序及跳转。
- 已发布问卷沿用第一阶段规则，先关闭为草稿再改题，重发后旧快照与答卷保留。
- 同一模板可在同一份问卷中多次使用，每次生成独立实例 ID，各自编辑和跳转。
- 问卷草稿继续保存完整题目副本及来源模板记录；发布时复制完整内容、来源和问卷内配置至不可变快照。
- 填写和答案解释使用对应发布快照，不动态读取模板正文。

## 3 共享及撤销

- 作者输入完整注册用户名精确查找接收者，大小写规则沿用第一阶段；显示匹配用户名并经确认后共享，不存在时提示。一份模板可分别共享给多个指定用户，不重复建立同一用户的有效授权；接收者从共享给我的模板入口查看。暂不提供公开模板广场或任何人可用的共享链接。
- 接收者不能直接转分享原模板；使用后修改并另存的新模板可以分享，仍保留来源。
- 共享题目不授予查看他人问卷、答卷或统计的权利。
- 撤销共享后，该接收者停止新的选用；从我的模板移除只影响自己的新选用，不影响其他用户；已复制并保存到问卷草稿的题目仍能编辑和发布，已有发布问卷和答卷不变。
- 分类收录不改变模板作者，也不能绕过当前共享权限；个人移除和恢复不改变共享；已经撤销的共享不会因恢复而重新授予。

## 4 个人题库与内容去重

- 采用个人题库，由创建者拥有和管理，不引入多人共同维护的公共题库。
- 一个用户可创建多个题库，一个模板可归入多个题库，也可主动取消全部分类后在全部题库中查看。默认提供“默认题库”；“全部题库”为汇总视图，同一模板 ID 只出现一次。保存时默认仅勾选默认题库，可多选及输入名称新建个人题库。
- 可收录自己的模板及当前获授权使用的共享模板。
- 题库归类只保存关联，不复制正文。移出题库只删除关联，删除题库不删除模板。
- 同一题库不能重复加入同一模板；不同模板的题型、题干、选项内容及顺序、必答和校验全部一致时，也视为内容重复。
- 模板 ID、作者、来源不同不算内容差异，问卷内位置和跳转不参与模板判重；判重范围是同一题库，不是全站或全部个人模板。
- 共享撤销后，对相应接收者隐藏；个人移除后，只从当前用户的模板及个人题库可选用列表隐藏；保留分类记录不能延续使用权限。
- 恢复模板时回到当前用户的全部模板列表；原个人题库仍存在且无内容重复则恢复收录，存在内容相同的另一模板则跳过该分类并提示，不覆盖或删除现有模板；原题库已删除则不重建。共享权限不随恢复重新授予。

## 5 跨问卷统计

- 只统计当前用户自己创建的不同问卷，不包含其他用户问卷，也不改变他人数据和权限。
- 默认合并同一来源模板且题干、题型、选项和校验限制一致的实例。仅必答、顺序、跳转不同仍可归组，需说明数据来源。
- 内容已改变的副本仍保留来源，但不自动并入原模板汇总；可查看问卷内统计，不强制另存模板。
- 累计所有已明确关联且符合条件的发布版本，可按问卷、发布版本、提交时间筛选。原问卷内统计仍默认最近发布版本。
- 有效回答逐次计数，回答人数跨问卷按账号去重；未答及跳过不计入。
- 单选各选项人数分别按账号去重；多选次数按有效回答累计；文本保留各次内容；数字平均值纳入每次有效回答。
- 匿名仍可由后台按账号去重，但不展示身份。
- 同卷重复使用的不同实例分别计次；同一答卷的同一实例不能因多条关联重复计数。
- 数字题展示回答次数、人数、平均值、最小值、最大值及按数值升序的频数和占比；占比分母为有效回答次数。无数据时显示暂无数据，不预设语义区间，数值多时可分页。

注意：题库判重包含必答设置，统计归并不以必答差异拆组，这是两个分别确认的口径。

## 6 模板使用情况

- 仅展示当前用户自己的问卷，不展示他人问卷信息或使用数量。
- 展示标题、状态、当前或仅历史使用、对应发布版本，以及副本内容是否修改。
- 按稳定问卷 ID 去重计数，可展开查看各发布版本。删除模板后保留历史来源关系。

## 7 数据结构调整

以下为已确认的结构方向；实际集合、字段及实现细节见项目中的设计说明.md 与 db.py。

| 集合或结构 | 调整 |
| --- | --- |
| users、sessions | 保留第一阶段账号和会话结构 |
| question_templates | 新增；完整固定内容、ownerId、直接来源模板、来源问卷及版本和实例、创建时间、旧删除字段仅作兼容保留；以来源关系表达历史及分支 |
| template_entries | 新增个人收录关系；userId、templateId、removed，删除只标记当前用户的移除状态 |
| question_shares | 新增；模板、接收者、授权者、共享状态及时间；避免重复有效授权 |
| question_banks | 新增；个人题库所有者、名称、说明、isDefault，每人一个系统默认题库 |
| question_bank_items | 新增；题库与模板关系、排序、加入时间；同库关联不重复，内容也需判重 |
| surveys.questions | 保留完整可编辑副本及实例 ID，增加来源模板记录；无模板来源的直接新建题目可为空 |
| survey_versions.questions | 新发布时保留完整内容、来源和问卷内配置；既有快照不倒改 |
| responses | 保留主结构及 answers 的 questionId、value；questionId 继续表示问卷内实例，不强制重复保存模板关联 |
| 模板来源映射 | 新增独立关联记录；模板、来源问卷、发布版本、题目实例，用于旧数据接入等已明确的来源关联 |

新答案通过发布版本取得实际题目和来源；旧答案通过来源映射关联。不改写历史答案或原幂等比较依据。共享、题库归类和模板正文分开，避免多处复制正文或在用户对象内维护增长的关联数组。

## 8 第一阶段兼容

- 旧问卷、发布快照、答卷全部保留，原有编辑、发布、填写、校验、匿名、重复限制、提交重试及统计继续可用。
- 不自动批量生成旧题模板，不按题干相同自动关联其他问卷。
- 用户主动从旧发布题目保存模板后，记录来源映射，使该来源版本已有答案可按权限和内容规则参与统计，不自动包含其他旧版本。
- 第二阶段在第一阶段源码基础上扩展，不推倒重做；实施时使用独立环境及数据库，保护第一阶段基线。

## 9 实现时须落实的验证

- 模板保存快照、内容校验、使用隔离、来源链及分支、删除与恢复。
- 共享禁止直接转分享、修改后另存可分享、撤销后阻止新选用、已有副本不受影响。
- 多题库归类、同库关联及内容去重、删除题库不删除模板。
- 内容一致归并、按账号和回答次数统计、匿名身份隐藏、跨用户数据隔离。
- 多次发布、同卷重复实例、关联去重、旧数据映射和历史幂等重试。
- 第一阶段原有功能回归，记录实际新测试结果，不以历史通过数替代。

## 10 尚需实现设计细化的边界

本轮集中列出的业务边界已全部确认。模板指单道题，题库是多个模板的集合；来源问卷草稿有未保存修改时，先保存当前草稿，成功后再把选中的单道题加入模板。保存失败不生成模板；其余题目可保持未完成状态，仍须符合原有草稿保存校验。已发布题目直接取发布快照，不需要重新保存发布内容。

查询索引、分页、错误提示等常规实现细节按已确认规则落实，不再逐项请求确认；若出现影响业务的新冲突，再集中讨论。

## 11 集中确认的边界规则

用户已明确采用集中问题中的全部十项；第 2 项在明确模板为单题后，确认先保存来源问卷草稿，再建立选中题目的模板。

- 来源历史逐个检查权限：自己的模板包括已删除内容可查看及恢复；他人模板仅当前共享有效时可查看正文，个人移除不删除历史；未获共享或共享撤销时保留来源节点并明确说明原因。自己的问卷副本和派生模板不受影响。
- 创建模板时同步记录来源题目及当时内容；后续问卷发布时按实际内容判断是否符合关联统计条件，不倒改旧快照。
- 从 A 使用、修改后另存 B，保留 A→B 的来源链及 B 的来源问卷题目，不抹去原来源；来源题目内容符合 B 时可参与 B 的统计。
- 使用模板后未修改内容，不生成新的派生模板，提示使用已有模板；不得通过未经修改的另存绕过禁止直接转分享的规则。
- 文本按原文比较，空格和换行差异算内容变化；数字按精确数值比较，1 与 1.0 相同。题库判重包含必答，统计归并不因必答不同拆组。
- 选项按内容和顺序比较，不因技术 ID 不同认定内容变化；保留选项对应关系以正确解释及统计答案，换序算变化。
- 修改后又恢复为原内容的题目，可按实际发布内容重新满足归并条件；不因曾经修改而永久排除，不同内容的历史发布版本仍分别判断。
- 来源链不代表统计自动合并；按选定模板的直接使用关系和明确来源映射查询，再检查内容一致性。
- 重复点击不产生重复模板；并发共享撤销、删除与选用以服务器核验结果为准；模板创建、来源关联及本次所选分类一起成功或失败，明确提示结果。来源问卷草稿若已先保存成功，不因后续模板创建失败丢失。

## 12 2026-10-27 体验反馈调整（用户已授权实现）

本节及上文更新的规则取代先前“删除模板自动停止全部共享”和“仅作者可删除”的解释。模板正文固定保留；自己的模板和收到的共享模板均可从个人列表移除，并可在权限仍有效时恢复。题库移除限定当前用户，不修改其他用户分类、共享或问卷。

来源历史明确显示“首次保存（无上游模板）”“已从我的模板移除”及“目前未共享或共享已撤销”；无权限仍不泄露来源正文，不因改善提示而放宽他人数据权限。

默认题库固定保留，可移出题目，不允许删除或改名；旧的同名可用题库沿用原 ID。旧未分类记录首次查看题库时尝试归入默认题库，已有自定义分类保留，后续不强制补回用户移出的分类。默认题库遇到内容重复时保留其原有收录，新模板保留在全部题库及其他所选题库并提示跳过，不重复收录；自定义题库仍严格拒绝同内容冲突。保存题库列表末尾提供“＋ 新建题库”，点击后才显示名称输入弹窗及“创建 / 取消”。点击创建成功即建立题库并在当前选择中勾选它、取消默认题库勾选，保留其他选择；连续创建的新题库都保持勾选。取消或失败不改变原选择。已创建的题库独立保留，不随之后取消模板保存而删除。

账号变化通知不在共享 Cookie 的窗口内建立独立登录空间。前端通过跨页面通知、返回页面核对和请求身份校验及时显示当前账号；不以新账号自动重试旧账号的修改。两个账号同时体验仍使用独立浏览器或普通/无痕环境。
